# Quinten Jin — personal site

Plain HTML, CSS, and JavaScript. No build step and no dependencies beyond Google Fonts.

| File | What it does |
| --- | --- |
| `index.html` | All page content. Edit text here. |
| `style.css` | Design tokens (colors and fonts at the top), layout, light/dark themes |
| `script.js` | Theme toggle, generated paper-cut rosettes, scroll reveal, nav highlighting |
| `papercut.js` | "Fold & cut" studio: canvas drawing mirrored through the dihedral group D<sub>n</sub> |
| `bspline.js` | B-spline playground: draggable control points with Cox–de Boor basis functions |

**Preview:** open `index.html` in a browser.

**Deploy (GitHub Pages):** push these files to a repo named `<your-github-username>.github.io` and the site goes live at that address. In any other repo, turn on Pages under *Settings → Pages* and it is served at `<username>.github.io/<repo>/`. All paths are relative, so both setups work.
